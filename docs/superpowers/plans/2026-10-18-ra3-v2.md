## Global Constraints
- Every phase of every case sums exactly 200 points; existing items ×0.5, new items sum 100.
- Every item id has a Spanish translation; every test id in the 13-test catalog appears in every case's phase-4 tests item.
- Content only from `docs/ra3-contingut.md` (diabetes screen excepted).
- Result text for Classroom stays Catalan; verification unchanged.
- Shuffle is deterministic per (email, item id); timeline items are not shuffled.

## Review Focus
1. Spanish mode: no Catalan string leaks in phase screens; switching language mid-phase keeps answers and score.
2. Shuffled options: stored answers are option ids, so reload and verification are unaffected.
3. Drag-and-drop on touch: dropping a card outside any bin leaves it unassigned, not lost.
4. Order item: partially correct order scores proportionally, never below the phase floor.
5. Diabetes screen and effects respect «Animacions: No».
